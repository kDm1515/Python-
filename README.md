
# COVID-19 Data Analysis using Pandas

## Description
A simple data analysis project using the Pandas library to analyze COVID-19 trends from a dataset.

## Features
- Data loading and cleaning
- Grouping and summarizing cases by country
- Time-series analysis for India
- Basic visualization with Pandas

## Dataset
The dataset used should be named `covid_19_data.csv` and placed in the same directory.

## How to Run
```bash
pip install pandas matplotlib
python covid_analysis.py
```
